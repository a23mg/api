# DummyJSON Products TUI 📦

แอปพลิเคชัน Terminal User Interface (TUI) สำหรับค้นหาและเลือกดูสินค้าจาก DummyJSON บน Terminal แบบโต้ตอบได้เต็มรูปแบบ

## วิธีการรันโปรแกรม

```bash
# รันผ่าน npm
npm start

# หรือรันผ่าน node ตรงๆ
node index.js
```

## ความสามารถและคีย์ลัด (Keybindings)

| คีย์ลัด | การทำงาน |
| :--- | :--- |
| **↑ / ↓** หรือ **k / j** | เลื่อนดูรายการสินค้าในฝั่งซ้าย (ฝั่งขวาจะแสดงรายละเอียดทันที) |
| **/** | เปิดหน้าต่างค้นหาสินค้า (พิมพ์คำค้นหา แล้วกด `Enter`) |
| **C** | เปิดเมนูเลือกดูสินค้าตามหมวดหมู่ (Category Picker) |
| **N** | ไปยังหน้าถัดไป (Next Page) |
| **P** | ย้อนกลับหน้าก่อนหน้า (Previous Page) |
| **R** | รีเซ็ตการค้นหา/หมวดหมู่ กลับสู่หน้าสินค้าทั้งหมด |
| **PageUp / PageDown** | เลื่อนอ่านรายละเอียดสินค้าในฝั่งขวา |
| **Esc** | ปิดหน้าต่าง Popup ค้นหาหรือเลือกหมวดหมู่ |
| **Q** หรือ **Ctrl+C** | ออกจากโปรแกรม |
